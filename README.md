#  About Me

> **Full-Stack Developer | AI/ML Engineer | Project Builder**

I'm **Priyanshu Joshi**, a B.Tech Computer Science & Engineering (AI & ML) student at **Aravali College of Engineering & Management**, passionate about building modern web applications, solving technical problems, and exploring the intersection of **Full-Stack Development and Artificial Intelligence**.

Currently, I'm focused on building **full-stack projects** and turning ideas into complete, functional applications — from designing responsive interfaces and writing frontend logic to developing backend systems, APIs, database integrations, authentication, debugging, and deployment. I believe the best way to learn technology is to **build, break, debug, improve, and build again**.

Alongside development, I'm strengthening my **C++ and Data Structures & Algorithms** skills while exploring **AI/ML, Python, and intelligent application development**. My goal is to become a versatile software engineer capable of building scalable products and integrating intelligent solutions into real-world applications.
